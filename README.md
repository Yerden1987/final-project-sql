# Итоговый проект по анализу данных — SQL

## Описание проекта

В данном проекте выполнен анализ клиентской базы и транзакций с использованием MySQL. Основная цель — исследовать покупательскую активность, средний чек, динамику транзакций и распределение клиентов по возрастным группам.

## Используемые технологии

- SQL
- MySQL 8.0
- MySQL Workbench

## Выполненные задачи

### 1. Анализ постоянных клиентов
- Определение клиентов, совершавших покупки каждый месяц в течение года.
- Расчёт среднего чека.
- Расчёт среднего количества покупок в месяц.
- Подсчёт общего количества транзакций.

### 2. Помесячный анализ транзакций
- Расчёт среднего чека по месяцам.
- Анализ количества операций и активных клиентов.
- Определение доли каждого месяца в общем количестве и сумме транзакций.
- Анализ распределения клиентов по полу и их доли в расходах.

### 3. Анализ возрастных групп
- Разделение клиентов на возрастные группы с интервалом 10 лет.
- Учёт клиентов с неизвестным возрастом.
- Расчёт сумм покупок и количества операций.
- Анализ квартальных показателей.

## Структура проекта

- `final_project.sql` — SQL-запросы для выполнения анализа.
- `README.md` — описание проекта.

## Источники данных

В анализе использованы данные о клиентах и их транзакциях за период с июня 2015 года по июнь 2016 года.

## Результат

Проект демонстрирует применение SQL для обработки данных, группировки, объединения таблиц и расчёта аналитических показателей, необходимых для изучения поведения клиентов.
